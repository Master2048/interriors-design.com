# Surface: portfolio.html

Mode: Experience
Audience: private clients evaluating the studio through completed interior work.
Job: scan six projects and open a dedicated project page with the full photo series.
Action: choose a project, inspect its gallery, then leave a request or return to the portfolio.
Proof: existing project photography under assets/img/portfolio only.
Constraints: inherit the services hub composition and tile design; keep the inner-page hero and shared navigation; no invented project facts.

## Direction contract

THESIS: The work itself leads, while the portfolio index behaves like the familiar services hub rather than a separate visual system.

OWN-WORLD: Near-black ground, Cormorant display, Manrope body, orange actions, glass header, real project photos, shared page-hero type, two-column flex tiles.

STORY: The visitor sees six distinct interiors, chooses one from an image-led tile, then explores its complete photo sequence on a quiet detail page.

FIRST VIEWPORT: Glass header over a full-bleed project still. Centered title and one supporting line. The next section begins with a centered heading followed by two-column project tiles.

FORM: Extension of the services hub pattern, code-led and fixed by the user's request; project cards open dedicated static detail pages.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
