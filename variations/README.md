# Вариации дизайна — YMG DESIGN

Команда: `+++variations(3, 1.7)` — три вариации на основе `../index.html`, температура **1.7** (максимальная / радикальные изменения).

Контент (тексты, услуги, шаги дорожной карты, портфолио) идентичен оригиналу. Отличаются: типографика, цветовая палитра, композиция макета, навигация и стиль ключевых компонентов — так, чтобы каждая вариация выглядела как самостоятельный, узнаваемо иной дизайн.

Все вариации используют общие изображения из `../assets/` (относительный путь `../../assets/...`), поэтому открывать их нужно как есть — не копируя файлы отдельно.

---

## Вариация 1 — «Terracotta Editorial»
📁 `index - variation 1/`

- **Шрифты:** `Fraunces` (акцидентный сериф с характером, для заголовков) + `Work Sans` (гротеск для текста/интерфейса).
- **Палитра:** тёплый шоколадно-коричневый фон, терракотовый акцент (вместо оригинального оранжевого).
- **Структура:**
  - верхняя тонкая utility-полоса с телефоном и графиком работы;
  - услуги — раскрывающийся аккордеон вместо сетки карточек;
  - дорожная карта — вертикальная таймлайн-линия с индикатором прогресса при скролле;
  - портфолио — горизонтальная карусель со свайпом/кнопками вместо статичной сетки;
  - карточка «полное меню» через доп. блок с фичей.
- **Ощущение:** редакционный журнал про архитектуру — тепло, фактурно, с крупной типографикой.

## Вариация 2 — «Swiss Grid Mono»
📁 `index - variation 2/`

- **Шрифты:** `Space Grotesk` (геометрический гротеск для заголовков и текста) + `IBM Plex Mono` (моноширинный — для лейблов, индексов, номеров, футера).
- **Палитра:** графитово-чёрный фон, приглушённый шалфейно-оливковый акцент, дуотон-фото в about.
- **Структура:**
  - швейцарская сетка: заголовки uppercase, разделённые шапки-секции (eyebrow + h2 + текст в две колонки);
  - услуги — табличный список-реестр с номерами вместо карточек;
  - дорожная карта — горизонтальный степпер со скролл-прогрессом;
  - портфолио — masonry-раскладка на CSS columns;
  - хедер на grid-раскладке (лого / центрированная навигация с индексами / контакты).
- **Ощущение:** строгий редакторский дизайн-стиль (Swiss design), техничный и «инженерный».

## Вариация 3 — «Glass Duotone»
📁 `index - variation 3/`

- **Шрифты:** `Bricolage Grotesque` (экспрессивный вариативный дисплейный шрифт) + `Inter` (нейтральный текстовый гротеск).
- **Палитра:** дуотон фиолетовый × циан на глубоком тёмно-синем фоне, множество стеклянных (glassmorphism) поверхностей с размытием.
- **Структура:**
  - плавающий «стеклянный» хедер-пилюля вместо полноширинной шапки;
  - hero — сплит-макет с анимированными блобами на фоне и фото в стеклянной рамке;
  - услуги и портфолио — карточки с 3D-tilt эффектом при движении мыши;
  - дорожная карта — «стеклянный» горизонтальный степпер с градиентной линией прогресса;
  - контакты — размытый фоновый снимок интерьера под стеклянной формой;
  - плавающий вертикальный док (кнопки «связаться» / «наверх» / «позвонить») вместо двух отдельных круглых кнопок;
  - футер — стеклянная плавающая панель.
- **Ощущение:** современный премиальный «продуктовый» стиль, много глубины и мягкого свечения.

### Функциональность (сохранена во всех трёх)

Во всех вариациях работают: preloader, скроллспай навигации, мобильное меню, скролл-реveal анимации, маска телефона, валидация и фейковая отправка обеих форм (основной и быстрой), модальное окно быстрой заявки, лайтбокс портфолио (свайп/клавиатура/счётчик), кнопка «наверх», футер с текущим годом.

### Как посмотреть

Откройте в браузере:
- `index - variation 1/index.html`
- `index - variation 2/index.html`
- `index - variation 3/index.html`

(Через локальный сервер — например OpenServer/OSPanel — чтобы относительные пути к `../../assets/` и веб-шрифтам Google Fonts работали корректно.)
